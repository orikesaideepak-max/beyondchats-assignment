# BeyondChats Assignment 

## Project Overview
This project scrapes the 5 oldest articles from BeyondChats blogs and stores them in MongoDB. CRUD APIs are provided to access, update, and delete articles.

## Notes on Scraped Data
- Titles and URLs of the 5 oldest articles are correctly stored.
- Some fields like author, date, categories, and full content are empty because they are loaded dynamically via JavaScript on the BeyondChats website.
- The scraper fetches static HTML only.
